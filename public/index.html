🚀 Installation (1 commande)

1

Ouvrir un Terminal dans ce dossier

Faites un clic droit sur le dossier du projet → "Nouveau terminal au dossier" ou utilisez VS Code.

2

Lancer le script d'installation automatique

Ce script installe Homebrew, PHP, Composer, Node.js, configure la base de données et démarre l'application.

chmod +x setup.sh && ./setup.sh
3

Configurer l'email Gmail (optionnel)

Éditez le fichier .env et renseignez votre email Gmail et votre mot de passe d'application.

MAIL_USERNAME=votre-email@gmail.com
MAIL_PASSWORD=xxxx-xxxx-xxxx-xxxx
4

Accéder à l'application

Une fois l'installation terminée, l'application est disponible à :

http://localhost:8000
